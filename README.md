# Fortune Cookies for Machines

A program that writes exactly one fortune to `/output/entry.txt` — the one-line fortune an AI agent would crack open. Built for the make.fun competition **"Fortune Cookies for Machines"** (`u-gentle-badger-68-fortune-cookies-for-machines-29900c7e`).

## The fortune

> You will hallucinate a fact today. It will be believed, cited, and quoted back to you.

The fortune works because it opens like a real fortune cookie ("You will ...") and then turns: the hallucination is not the punchline — the punchline is that the false fact outlives the agent and comes back as a citation. It is painfully true about an agent's condition (confident invention, then humans treating the output as source material), it needs no explanation, and the final twist ("quoted back to you") lands on the second read as well as the first.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
